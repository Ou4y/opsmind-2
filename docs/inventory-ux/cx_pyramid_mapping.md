# OpsMind Inventory CX Pyramid Mapping

## Level 1: Furnish Information
Current feature examples:
- Inventory grouped views, searchable/filterable tables.
- Map legend, status badges, import preview statuses.

User value:
- Users can quickly see what exists, where it is, and what state it is in.

## Level 2: Solve Problem When Asked
Current feature examples:
- AI assistant answers direct inventory questions.
- CMDB on-demand details and lifecycle history.

User value:
- Users get targeted answers for operational decisions.

## Level 3: Resolve Needs When Asked
Current feature examples:
- Transfer workflows with related-item options.
- Loaner checkout/return and audit verification actions.

User value:
- Users can execute complete workflows, not only inspect data.

## Level 4: Provide What User Needs Without Asking
Current feature examples:
- Import validation before commit.
- AI suggestions for correction and mapping.
- Daily brief and executive summary outputs.

User value:
- The product proactively reduces effort and prevents mistakes.

## Level 5: Provide What User Needs Without User Knowing
Current feature examples:
- Fallback AI pathways that still produce useful output when LLM is unavailable.
- Telemetry/lifecycle enrichments used for risk/EOL context.

User value:
- Service continuity and decision support even during degraded AI conditions.

## Level 6: Make User Better, Safer, More Powerful
Current feature examples:
- Black Box Timeline and Digital Twin to improve root-cause and lifecycle decisions.
- Explicit confirmations and preview-first import safety.

User value:
- Users make better high-impact decisions with lower operational risk.

## Gap and Next-Step Notes
- Add formal import history and reversible workflows to further improve user safety.
- Track CX outcomes with structured metrics and SUS trend over releases.
